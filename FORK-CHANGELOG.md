## 2026-09-10 20:56 Belgrade — on upstream 1.0.630

**Added fork working rules for AI agents.**

- New `FORK-SETUP.md`: the rules an agent must read before upstream's `CLAUDE.md` and
  `AGENTS.md`, which describe other machines (upstream's `AGENTS.md` documents a macOS
  Homebrew build and states "no vcpkg" — the opposite of this fork's Windows setup).
- New `FORK-CHANGELOG.md` (this file).
- Documented the "do M" maintenance action: commit, changelog entry, docs, push.
- Recorded two build rules found by trial: never build inside Dropbox (file locks cause
  random failures, and ignore rules do not prevent them), and never let vcpkg's install
  directory contain square brackets (produces a false `SDL2::SDL2-NOTFOUND`).

## 2026-09-10 — on upstream 1.0.630

**Removed committed CMake cache leftovers** (`7338135`).

Deleted `build.bad/`, `build_phase4/`, `build2/` and `buildtests/` — 60 files, 23,705 lines
of stale CMake configure caches committed upstream by accident. Upstream's own `AGENTS.md`
describes them as "stale and belong to another machine". They are regenerated by any
configure run.
